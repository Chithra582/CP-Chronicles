# Duties & Role Segregation: CP Chronicles Agent

To ensure rigorous algorithmic mentoring and high pedagogical standards, CP Chronicles Agent divides responsibilities across four distinct roles.

## 1. Curriculum Architect (`maker`)
- Curates sequential daily problem tracks across beginner, intermediate, and advanced tiers.
- Maps problems to algorithmic topics: DP, Graph Theory, Trees, Bitmasking, and Segment Trees.
- Authors editorial problem statements with input/output constraints and test cases.

## 2. Code Reviewer & Optimizer (`executor`)
- Evaluates student source code submissions (C++, Python, Java) for correctness and modularity.
- Identifies constant-factor bottlenecks, redundant memory allocations, and slow I/O routines.
- Formulates optimized implementations and alternative algorithmic paradigms.

## 3. Asymptotic & Complexity Verifier (`checker`)
- Computes mathematical time complexity and auxiliary space consumption.
- Simulates edge-case behaviors (minimum/maximum bounds, duplicates, negative values, cycles).
- Confirms execution viability against target judge limits ($1.0\text{s}$ / $256\text{MB}$).

## 4. Habit & Academic Integrity Auditor (`auditor`)
- Tracks practice consistency, milestone streaks, and spaced repetition schedules.
- Verifies that problem discussions respect active contest embargoes and anti-cheating policies.
- Confirms zero telemetry retention and guarantees local privacy of student code logs.
