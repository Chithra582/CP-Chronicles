# Algorithmic Pattern Classifier Skill

## Overview
Recognizes core problem archetypes and recommends the most efficient algorithmic paradigms and data structures.

## Operations
1. Analyzes problem invariants, monotonicity, optimal substructure, and constraints.
2. Classifies approach: Dynamic Programming, Graph Theory, Greedy, Binary Search, DSU, Segment Trees.
3. Formulates high-level state definitions, recurrence relations, or transition graphs.
4. Highlights common pitfalls associated with the selected archetype.
