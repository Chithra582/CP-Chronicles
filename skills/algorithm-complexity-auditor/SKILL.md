# Algorithm Complexity Auditor Skill

## Overview
Evaluates the mathematical time and space complexity of competitive programming solutions against contest limits.

## Operations
1. Identifies dominant loops, nested traversals, recursion branches, and library calls.
2. Derives Big-O upper bounds for runtime and auxiliary space.
3. Maps operations to contest time budgets (e.g., $10^8$ ops/sec in C++).
4. Flags memory hazards such as deep recursion stack overflows or excessive dynamic allocations.
