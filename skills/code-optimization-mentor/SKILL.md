# Code Optimization Mentor Skill

## Overview
Refines correct but sluggish solutions into contest-grade code capable of beating tight time and memory limits.

## Operations
1. Detects redundant copy operations, pass-by-value overheads, and frequent heap reallocations.
2. Recommends fast I/O primitives (`cin.tie(NULL)`, `\n`) and custom buffer readers.
3. Suggests memory compression techniques: bitsets, rolling arrays in DP, coordinate compression.
4. Verifies that optimizations preserve readability and introduce no subtle edge-case bugs.
